========================================================================================
QUESTÃO 1: FLUXO SIMPLES DE LOGIN (Cliente -> API Node.js -> PostgreSQL -> JWT)
========================================================================================

+---------+                +--------------+                +------------+                +------------+
| Cliente |                | API Node.js  |                | PostgreSQL |                | Módulo JWT |
+----+----+                +------+-------+                +-----+------+                +-----+------+
     |                            |                              |                             |
     | 1. POST /login             |                              |                             |
     |    { email, password }     |                              |                             |
     |--------------------------->|                              |                             |
     |                            | 2. SELECT id, password_hash  |                             |
     |                            |    FROM users WHERE email=$1 |                             |
     |                            |----------------------------->|                             |
     |                            |                              |                             |
     |                            | 3. Retorna dados do usuário  |                             |
     |                            |<-----------------------------|                             |
     |                            |                              |                             |
     |                            | 4. Valida senha com bcrypt   |                             |
     |                            |    bcrypt.compare(senha,hash)|                             |
     |                            |---------------+              |                             |
     |                            |               |              |                             |
     |                            |<--------------+              |                             |
     |                            |                              |                             |
     |      [SE CREDENCIAIS VÁLIDAS]                             |                             |
     |                            | 5. Gera e assina o Token     |                             |
     |                            |    jwt.sign({ sub: id }, KEY)|                             |
     |                            |----------------------------------------------------------->|
     |                            |                              |                             |
     |                            | 6. Retorna string do JWT     |                             |
     |                            |<-----------------------------------------------------------|
     |                            |                              |                             |
     | 7a. HTTP 200 OK            |                              |                             |
     |     { accessToken: "eyJ..."}                              |                             |
     |<---------------------------|                              |                             |
     |                            |                              |                             |
     |      [SE CREDENCIAIS INVÁLIDAS]                           |                             |
     | 7b. HTTP 401 Unauthorized  |                              |                             |
     |     { error: "Inválido" }  |                              |                             |
     |<---------------------------|                              |                             |
+----+----+                +------+-------+                +-----+------+                +-----+------+
